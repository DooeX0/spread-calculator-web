# Калькулятор спреда GRAM

Веб-калькулятор покупки GRAM на Bybit и продажи за рубли через Walt P2P. Расчёт и история работают в браузере. Покупку можно рассчитать по публичному стакану Bybit или по введённой вручную цене. Цена из Walt и комиссия вывода вводятся вручную.

Сайт размещается через GitHub Pages из корня ветки `main`.
